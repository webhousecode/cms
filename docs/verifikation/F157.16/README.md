# F157.16 — runtime-bevis fra produktion

Stillbilleder fra Lens-kørsler mod **den levende broberg.ai** 7. september 2026,
lagt i repoet fordi en daemon-artefakt bag `127.0.0.1` hverken kan åbnes af
ejeren eller overleve en disk der ryddes — mens henvisningen til den bliver ved
med at læse som et bevis.

| Fil | Hvad det viser | Flow |
|---|---|---|
| `voks-efter-gem.png` | En pille tilføjet med «+» og skrevet færdig, renderet i rækken | `30188705-64ba-40a3-88b9-a5e8cc16d9c4` (10/10 trin) |
| `skrump-bekraeftelse.png` | Husets mønster inde i pillen: «Fjern? [Ja] [Nej]» — ingen native dialog | `e0daa8fa-c359-4d85-a4b7-16cc7e2d4217` (12/12) |
| `skrump-efter.png` | Rækken tilbage på sine syv rigtige pille — ingen rest | samme flow |

Den bærende måling står ikke på et billede: den nye pille blev læst tilbage fra
en **almindelig sideindlæsning uden `?cms_edit=`**, altså det en besøgende ser.
Før prøven: 7 tags. Efter hele rundturen: de samme 7, byte for byte.

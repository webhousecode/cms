# F199.7 — @broberg/sso 0.4.0 → 0.5.0

**Ordre:** Christian 29/9-2026: «sso 0.5.0 er den du skal op på nu».

## Scope
- Bump exact-pin til 0.5.0 og opdatér frozen-deps-ledgeren.
- Non-goal: at TAGE `inviteUsers()` / `migrationStatus()` i brug i cms-admin og at sætte `BID_APP_KEY` på Fly. Det hører til invitationsflowet (næste redaktør) og er et env-skift, der kræver Christians ord.

## Risiko
Målt: public API-diff 0.4.0→0.5.0 er kun nye metoder (`inviteUsers`, `migrationStatus`), nye typer, `MAX_INVITATIONS` og en valgfri `timeoutMs`. Ingen ændringer i dependencies/exports-kort.

## Bevis
47 tests i BID-suiten grønne mod installeret 0.5.0; tsc ren; live-probe af login-omstillingen efter deploy.

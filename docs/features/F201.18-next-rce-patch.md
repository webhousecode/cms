# F201.18 — Next.js 16.3.8 (GHSA-vcvr-r3jv-pc5j)

## Motivation
Security Gate's afhængigheds-audit har været rød siden 30/9: kritisk «Next.js: Remote Code Execution in next/og ImageResponse» (GHSA-vcvr-r3jv-pc5j), sårbare versioner >=16.2.0 <16.3.6. cms-admin kører 16.3.3.

Målt: cms-admin's kildekode bruger hverken `next/og` eller `ImageResponse`, så sårbarheden kan efter alt at dømme ikke udnyttes i webhouse.app. Opdateringen er alligevel en patch-version inden for den eksisterende range og skal ind.

## Scope
`next` 16.3.3 → 16.3.8 i cms-admin (seneste patch). Typecheck + vitest + udrulning + Lens.

## Non-goals
De øvrige high-fund i audit'en (fx picomatch ReDoS) — separat kort hvis de ikke forsvinder med opdateringen.

## Reuse
Ingen.

## Rollout
Grøn port → push → auto-deploy → Lens.

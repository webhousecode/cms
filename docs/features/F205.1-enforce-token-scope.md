# F205.1 — Håndhæv nøglens site og rettigheder

Del af F205 (se docs/features/F205-scoped-access-tokens.md for motivation og målinger).

## Opgave

1. Inventér alle wh_-nøgler i prod (navn, scopes, sites, sidste brug) — uden at læse nøgleværdier.
2. proxy.ts:388-406: mint sessionen med nøglens scopes + sites; `role: admin` kun når scopes indeholder `*`.
3. `getSiteRole()` returnerer ingen adgang når aktivt site ligger uden for nøglens sites.
4. `hasPermission()` bruger nøglens scopes (mappet via én tabel, så `content:write` ↔ `content.edit` ikke driver).
5. Ship-dark: først log-only-flag, så håndhævelse.

## Test

Vitest der kalder proxy + en rute med Bearer: tilladt site/permission → 200, andet site → 403, admin-rute → 403. Mutationstjek på site-tjekket.

## Risiko

Load-bearing auth-kæde. CMS_ADMIN_TOKEN bruges af broberg-ai-site og cms-sessioner til indholdsskrivning; den skal måles uændret efter deploy.

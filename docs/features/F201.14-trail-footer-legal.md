# F201.14 — trailmem.com: Privacy og Terms i footeren

## Motivation
F201.13 publicerede /terms og opdaterede /privacy på trailmem.com. trail (#34001) bad om et link til /terms i footeren ved siden af /privacy. Målt: footeren har ingen af dem — kun Twitter, GitHub og Status (`global.footerLinks`). En juridisk side ingen kan finde fra forsiden, hjælper ikke den der leder.

## Scope
Tilføj `{label: "Privacy", href: "/privacy/"}` og `{label: "Terms", href: "/terms/"}` sidst i `footerLinks` via CMS-API'et. De eksisterende tre røres ikke. Udrul fra webhouse.app, Lens mod prod.

## Non-goals
Rydde de døde `#`-links (Twitter, Status) — trails beslutning; nævnt for dem.

## Reuse
Eksisterende footerLinks-felt; ingen kode.

## Rollout
PATCH → read-back → deploy → Lens → besked til trail.

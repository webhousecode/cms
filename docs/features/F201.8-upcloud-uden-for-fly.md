# F201.8 — UpCloud (København) på broberg.ai/trust

## Motivation
broberg-ai (#33897) videregiver fd-sundhed (#33896, på Christians ordre): fra 30/9 kører **UpCloud Managed PostgreSQL** i `dk-cph1` (København) som live standby-kopi af FD Sundheds database — og Broberg ID's standby på samme konto. Selskabet er **UpCloud Oy, Helsinki** (EU); **data ligger i Danmark**; overførsel inden for EU. Kilde: `broberg-ai/fd-sundhed` 69d4f112, `infra/replika-upcloud/runbook.md`.

Listen på broberg.ai/trust skal vise den. Den lover selv at en ny leverandør står der, når den er i brug.

## Hvorfor det ikke bare er en række mere
`compliance/subprocessors.public.json` skrives af `scripts/compliance-scan.ts` — en håndskrevet række forsvinder ved næste scan. Og scan måler drift **kun** gennem kørende Fly-apps (secret-navne + målte endpoints). UpCloud-kopien abonnerer direkte fra Supabase; ingen Fly-app bærer en nøgle til den. Kæden kan altså ikke se den, og det vil ramme den næste leverandør uden for Fly på samme måde.

## Scope
1. `VENDORS`: `upcloud` (env `^UPCLOUD_`, vært `upclouddatabases.com` / `upcloud.com`).
2. `Assessment.in_production_outside_fly?: { at, by, evidence }` — spejlet af `not_in_production`: en registrering der overstyrer målingen skal sige hvornår, af hvem og på hvilket grundlag. `applyOwnerRulings` lægger den til drifts-mængden; `signedRecordProblem` afviser en halv registrering.
3. `assessments.json`: UpCloud med DPA-link (HTTP målt), `transfer_basis: EU`, `company_country: Finland`, placering Danmark (`measured: true`, aflst af fd-sundhed i egen opsætning 30/9), offentligt navn/formål DA+EN.
4. Kør scan → ny offentlig JSON → `scripts/trust-publish.ts` → læs tilbage strict → Lens.

## Non-goals
- Fly-rækken ændres ikke: fd-sundhed-replika på Fly lukkes måske, men Fly forbliver hosting.
- Sidens tekst om varsel til nye leverandører — ejerens/broberg-ai's afgørelse, rejst separat.

## Reuse
Ingen ny komponent; udvider den eksisterende F201-kæde (compliance-scan.ts + trust-publish.ts).

## Test
`compliance-scan.test` (eller tilsvarende): en `in_production_outside_fly` med kilde → leverandøren kommer på den offentlige liste; uden `evidence` → `signedRecordProblem` melder fejl. Mutation: fjern overstyringen i `applyOwnerRulings` → rød.

## Rollout
Grøn port → commit + push → trust-publish mod webhouse.app (broberg-ai site) → Lens → besked til broberg-ai.

# F157.20 — Inline-redigering uden CMS (gem-adapter, selector, inline-script)

**Forælder:** F157 Inline Editing · **Bestilt af:** cardmem (#3798, videresendt af components) til cardmem-F400 · **Prioriteret af:** Christian 22/10-2026: «B og derefter fortsæt med A» og «Inline edit skal jeg bruge nu i cardmem».

## Motivation
cardmems mockup-visning skal kunne rette tekst direkte i en mockup, «sådan som husets inline-edit i cms», kun almindelig tekst. Mockuppen kører i en sandkasse-iframe uden adgang til CMS'et og sender gemning ud via postMessage. Pakken `@broberg/cms-inline-edit` 0.12.0 kan i dag kun gemme direkte mod CMS-API'et med et token og binder kun til `[data-cms-field]`.

## Scope
1. **Gem-adapter** — `initInlineEdit({ adapter: { save(el, value): Promise<void> } })`. Med en adapter: ingen token, ingen `cmsBaseUrl`/`siteId`, intet kald til CMS'et; felterne er redigerbare med det samme (ingen login-pille/badge — værten styrer selv sin UI). Gem-pillen (Gemmer…/Gemt ✓/Fejl) og `plainTextWithBreaks` genbruges. CMS-API'et forbliver standardvejen når ingen adapter gives.
2. **Selector** — `selector` option, default `[data-cms-field]`.
3. **Kun almindelig tekst i adapter-mode** — felter markeret richtext/html wires som almindelige tekstfelter (ingen toolbar, ingen side-opslag mod CMS).
4. **Inline-script** — en IIFE-build (`dist/index.global.js`, global `CmsInlineEdit`) uden eksterne imports, eksporteret som `@broberg/cms-inline-edit/iife`, så den kan lægges ind som ét `<script>` i en null-origin iframe.

## Non-goals
- Rich text / toolbar / links / farver i adapter-mode.
- postMessage-protokollen mellem iframe og cardmem — den ejer cardmem (adapterens `save` er stedet de kalder den fra).
- Ændringer i CMS-mode for eksisterende sites.

## Reuse
Udvider husets egen pakke (`@broberg/cms-inline-edit`, ejet af cms) frem for at cardmem bygger en kopi. Ingen ny afhængighed; tsup har allerede `iife`-format.

## Arkitektur-skitse
- `InlineEditOptions`: `cmsBaseUrl`/`siteId` bliver valgfri på typen (krævet når der ingen adapter er — fejl i konsollen og ingen init ellers), + `adapter?`, + `selector?`.
- `initInlineEdit`: hvis adapter → `setupFields("", resolved)` + edit-mode uden badge; ellers uændret.
- `saveField`: hvis adapter → pille + `adapter.save(el, value)`; ellers uændret GET→PATCH.
- `wireField`: i adapter-mode springes rich-grenene over.
- `rescanFields`/observer: bruger `selector`; i adapter-mode intet token-tjek.
- tsup: ekstra entry med `format: ['iife']`, `globalName: 'CmsInlineEdit'`.

## Rollout
Tests → build → version 0.13.0 → publish via det eksisterende npm-workflow → besked til cardmem med version og brug.

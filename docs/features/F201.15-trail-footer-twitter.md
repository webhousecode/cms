# F201.15 — trailmem.com: fjern Twitter fra footeren

## Motivation
trail (#34015), Christians ord: «vi har ingen Twitter-profil og skal heller ikke have det». Footeren på trailmem.com havde et Twitter-link der pegede på `#` — et link til ingenting, der lover en profil der ikke findes.

## Scope
Fjern `{label: "Twitter", href: "#"}` fra `global.footerLinks` på site `trail` via CMS-API'et; de øvrige links røres ikke. Udrul fra webhouse.app, Lens mod prod.

## Non-goals
- Erstatte det med X eller andet (udtrykkeligt fravalgt).
- «Status» (`#`) — trail spørger Christian.

## Reuse
Eksisterende footerLinks-felt.

## Rollout
PATCH → read-back → deploy → Lens → besked til trail.

# F201.9 — /trust: nye leverandører listes når de tages i brug

## Motivation
Christian 30/9, direkte: «Ret teksten til: nye leverandører listes når de tages i brug». Leverandørlisten på broberg.ai/trust lovede at en ny leverandør står der mindst 30 dage før den tages i brug. UpCloud (F201.8) blev taget i brug samme dag den blev listet, så løftet var usandt.

## Scope
- Indledningen i `scripts/trust-publish.ts` (DA + EN): 30-dages-sætningen erstattes af «Nye leverandører kommer på listen, når vi tager dem i brug.» / «New suppliers are added to this list when we start using them.»
- Kør `trust-publish.ts` → globals + en-globals skrevet og læst tilbage byte-for-byte → Lens mod prod.

## Non-goals
Ingen ændring af listen selv eller andre dele af /trust.

## Reuse
Eksisterende F201.4-kæde (trust-publish.ts).

## Rollout
Commit + push, publish direkte til CMS'et (ingen deploy af cms nødvendig), Lens.
